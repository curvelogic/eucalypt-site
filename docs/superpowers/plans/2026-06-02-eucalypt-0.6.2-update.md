### Task 3: Add new feature examples

**Bead:** eucalypt-playground-9wf.3

**Files:**

- [ ] **Step 1: Add List Comprehensions example**

Add to the `EXAMPLES` array in `src/examples.ts`:

```typescript
{
  name: "List Comprehensions",
  format: "yaml",
  source: `pairs: { :for x: [1, 2, 3] y: [10, 20] }.(x + y)
triples: { :for a: [3, 5] b: [4, 12] }.(a * a + b * b)`,
},
```

This demonstrates the `:for` monadic list comprehension — cartesian product with dependent computation.

- [ ] **Step 2: Add Type Annotations example**

```typescript
{
  name: "Type Annotations",
  format: "yaml",
  source: `\` { type: "number → number" }
double(x): x * 2

\` { type: "[number] → number" }
sum(xs): xs foldl(+, 0)

result: [1, 2, 3] map(double) sum`,
},
```

This demonstrates the gradual type system — annotations as checked documentation.

- [ ] **Step 3: Add Safe Navigation example**

```typescript
{
  name: "Safe Navigation",
  format: "yaml",
  source: `data: {server: {host: "localhost" port: 8080}}

host: data ~ :server ~ :host
port: data ~ :server ~ :port
missing: data ~ :server ~ :timeout
deep-miss: data ~ :cache ~ :ttl`,
},
```

This demonstrates `~` for null-safe property access — returns null instead of erroring on missing keys.

- [ ] **Step 4: Add Multi-way Conditional example**

```typescript
{
  name: "Multi-way Conditional",
  format: "yaml",
  source: `grade(score): cond[score >= 90 => "A"
                    , score >= 80 => "B"
                    , score >= 70 => "C"
                    , "F"]

grades: [95, 82, 65, 91, 73] map(grade)`,
},
```

This demonstrates `cond[... => ...]` — the new multi-way conditional with the `=>` clause operator.
